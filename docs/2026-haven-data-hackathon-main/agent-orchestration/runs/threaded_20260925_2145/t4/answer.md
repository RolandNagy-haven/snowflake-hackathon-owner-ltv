# master: How does that compare with the 2025 season at the same point last year?

The 2026 season is running below last year: the cancellation rate is **5.68%**, down **0.75 percentage points** from **6.43%** at the same point in the 2025 season.

| Metric | 2025 (as at 25 Sep 2025) | 2026 (as at 25 Sep 2026) | Change |
|---|---:|---:|---:|
| Firm bookings | 957,647 | 1,039,538 | +81,891 (+8.5%) |
| Cancelled bookings | 65,804 | 62,633 | −3,171 (−4.8%) |
| Total (firm + cancelled) | 1,023,451 | 1,102,171 | +78,720 (+7.7%) |
| Cancellation rate | 6.43% | 5.68% | −0.75 pp |

The improvement comes from both sides — more firm bookings (+8.5%) and fewer cancellations in absolute terms (−4.8%).

**Basis (Bookings specialist):** Like-for-like snapshots (25 Sep each year); rate = cancelled ÷ (firm + cancelled) by booking volume, offers excluded; identical definitions across both seasons.
